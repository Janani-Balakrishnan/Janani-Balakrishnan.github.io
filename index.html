AI-Powered E-Learning Platform

An end-to-end learning platform where AI agents plan curricula, write lessons and generate course videos.

  • RAG content engine: the AI core in Python (FastAPI, PostgreSQL), generating context-aware learning content with LLMs and RAG.
  • Multi-agent pipelines: agents for curriculum planning, lesson content and AI course-video generation using Gemini, Veo and Google TTS/STT.

  • University data pipelines: Firecrawl and Selenium pipelines that scrape and structure US university data, powering analytics that help students compare universities.
  • Learner experience: Study Planner, Courses, AI Chat, Notebook, Quiz and Flashcard modules in React and TypeScript.
  • Cloud and payments: Docker-based FastAPI microservices on Cloud Run, CI/CD via Cloud Build and GitHub Actions, Stripe subscriptions, and Google, Microsoft and Facebook OAuth with JWT.

How I build

A few habits that run through all of the work above.

01

Ground every answer

Retrieval checks, cited sources and an honest “not found” beat a confident wrong answer. Numbers come from data, not from the model.

02

Fail safely between agents

Agents hand each other validated, structured outputs with retries, so one bad step never quietly spoils the rest of the pipeline.

03

Ship end to end

From the prompt to the React screen, Stripe billing, OAuth and the Cloud Run deploy, with AI-assisted development and human review on every change.
